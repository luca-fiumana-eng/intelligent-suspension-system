# Project summary

**Intelligent Suspension System — Electronic HTS Lock & Safety Interlock**

I conceived, designed, prototyped and patented an electronic actuation and control solution for a hydraulic tilting system used on three- and four-wheel scooters. My work covered mechanical integration, electrical architecture, wiring harness design and build, embedded firmware, fault handling, prototype debugging and vehicle validation.

The system provides a handlebar-operated OPEN/CLOSED function with a safety-priority automatic release. Firmware v2.0 uses a non-blocking state machine, Hall-effect wheel-speed sensing, derived acceleration, limit-switch feedback, movement timeouts, latched fault handling and telemetry.

**Evidence:** two prototypes built; bench debugging and vehicle integration; road-testing activity recorded at QJ Motor (China); PC-based firmware simulation with nine test scenarios.

**Technology:** Arduino Mega 2560, embedded C++, DC motor/H-bridge, Hall sensor, signal conditioning, automotive wiring, finite-state machine, fault handling and telemetry.
